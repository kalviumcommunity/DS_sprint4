PART A: KNOWLEDGE ASSESSMENT
================================================================================

[ ] Understand what a Jupyter kernel is
    - The kernel is a Python interpreter running in the background
    - The notebook is a frontend interface to the kernel
    - Kernel maintains memory/state between cell executions

[ ] Understand kernel state and persistence
    - Variables defined in Cell 1 are accessible in Cell 5
    - Deleting a cell from the notebook doesn't clear its variables from kernel memory
    - Restarting the kernel clears ALL variables

[ ] Know the difference between interrupt and restart
    - Interrupt (Ctrl+C): Stops current cell, keeps other variables
    - Restart (Kernel → Restart): Clears all variables, starts fresh

[ ] Understand execution order importance
    - Cells should run top-to-bottom (Cell 1 → Cell 2 → ... → Cell N)
    - Running Cell 5 only (skipping Cell 1-4) may fail if Cell 5 depends on earlier setup
    - Professional notebooks don't have hidden dependencies

[ ] Know the reproducibility test
    - "Restart & Run All" means: Restart kernel, then execute all cells
    - If this works, notebook is reproducible for anyone
    - Essential before sharing/submitting

PART H: COMMON ISSUES AND FIXES
================================================================================

Issue: "Cell shows an error about a variable not being defined"
Solution: 
  1. Verify you ran the cell that defines the variable
  2. Check the cell number where variable is defined
  3. Ensure cells run in order (Cell 1 → Cell 2 → ...)
  4. Try "Kernel → Run All Cells" to run everything in order
  5. If still broken, restart kernel and rerun all cells

Issue: "My interrupt doesn't work (cell keeps running)"
Solution:
  1. Verify the cell has a pause (time.sleep) or long loop
  2. Try Ctrl+C in terminal (not the notebook button)
  3. Try clicking the Stop button (⏹) in the notebook toolbar
  4. If neither works, restart the kernel
  5. Always test interrupt with the provided demo cell first

Issue: "After restart, I can't find my variables"
Solution:
  1. This is expected! Restart clears memory
  2. To restore, run all cells from Cell 1: "Kernel → Run All Cells"
  3. Or manually run cells in order
  4. Check the "Reproducibility Check" section to verify all variables restored

Issue: "My notebook has hidden dependencies I didn't realize"
Solution:
  1. Restart the kernel first (clears all memory)
  2. Then try "Kernel → Run All Cells"
  3. Any cell that fails reveals a dependency
  4. Fix by moving setup code earlier or adding comments
  5. Test again until all cells pass from scratch
