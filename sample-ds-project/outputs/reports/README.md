# Reports

**Purpose:** Store analysis reports and summary outputs

This folder contains reports and summaries generated by your analysis:
- HTML analysis reports
- PDF summary documents
- CSV exports for stakeholders
- Markdown documentation

## Report Types

**HTML Reports:**
- Interactive visualizations
- Formatted analysis summaries
- Documentation with styling
- Easy to share

**PDF Reports:**
- Print-friendly format
- Executive summaries
- Formal documentation
- Archived results

**CSV Exports:**
- Data for stakeholders
- Summary statistics
- Model predictions
- Export for external tools

## Example Reports

```
reports/
├── model_performance_report.html    # Interactive report
├── executive_summary.pdf            # Formal summary
├── customer_segments_export.csv     # For stakeholders
└── quarterly_analysis_summary.txt   # Text summary
```

## Generating Reports

### From Pandas DataFrame:

```python
# Save to CSV
summary_stats = df.describe()
summary_stats.to_csv('../outputs/reports/summary_statistics.csv')

# Export for stakeholders
customer_segments.to_csv('../outputs/reports/customer_segments_export.csv')
```

### HTML from Notebook:

```python
# Using jupyterlab or nbconvert
# jupyter nbconvert --to html --output=../outputs/reports/analysis.html notebook.ipynb
```

### Markdown Report:

```python
# Generate markdown
report = """
# Analysis Report
## Key Findings
- Finding 1
- Finding 2

## Recommendations
- Recommendation 1
"""

with open('../outputs/reports/summary.md', 'w') as f:
    f.write(report)
```
