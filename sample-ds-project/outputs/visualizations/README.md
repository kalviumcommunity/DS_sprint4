# Visualizations

**Purpose:** Store generated plots, charts, and visual outputs

This folder contains all visualization files generated by your analysis:
- Exploratory data analysis plots
- Model evaluation visualizations
- Results comparisons
- Dashboard screenshots

## Naming Convention

Use descriptive names that indicate content:

**Good:**
- `feature_distribution_all_features.png`
- `correlation_heatmap.png`
- `model_confusion_matrix.png`
- `forecast_vs_actual_30days.png`

**Bad:**
- `plot.png` (which plot?)
- `chart.png` (what chart?)
- `plot1.png`, `plot2.png`

## File Format

- **PNG:** Best for plots and charts (*.png)
- **PDF:** Best for reports and publication (*pdf)
- **SVG:** Best for diagrams and scalable graphics (*.svg)

**Recommendation:** Save as PNG (good quality, reasonable file size)

## Saving from Code

```python
# From notebook
plt.savefig('../outputs/visualizations/feature_distribution.png', dpi=300)

# Or with pathlib
from pathlib import Path
output_path = Path('../outputs/visualizations/correlation_heatmap.png')
plt.savefig(output_path)
```
