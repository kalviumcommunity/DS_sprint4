# Documentation

## Project Documentation

This folder contains explanatory documentation for the project.

## Files

### DATA_DICTIONARY.md

Complete reference for every data column in processed datasets.

**Includes:**
- Column name and data type
- Human-readable description
- Example values
- Valid ranges
- Notes about handling

**Use when:**
- Working with new dataset
- Uncertain about column meaning
- Writing analysis documentation
- Sharing data with others

### PROCESSING_LOG.md

Brief logs of data processing activities.

**Records:**
- When processing occurred
- What was processed
- Results summary
- Any issues encountered

## Adding Documentation

When adding new datasets or analyses, create a brief note here explaining:
- What data was used
- What was done
- Key results
- Any issues encountered

This helps teammates understand project history and decisions.
